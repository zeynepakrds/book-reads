# BookReads 📚

BookReads is a Goodreads-inspired reading tracker with gamification features.

This project is being developed by a team of seven students as part of the AI-Based Development course.

## Project Goal

Our goal is to build an application that encourages consistent reading habits by combining book tracking with XP, reading streaks, personal goals, and book quizzes.

## Planned Features

- Search for books using Google Books API
- Organize books into reading lists
- Track reading progress
- Earn XP through reading activities
- Maintain daily or weekly reading streaks
- Complete book-related quizzes
- View personal reading statistics

These features are planned and will be developed incrementally.

## Proposed Tech Stack

| Layer | Technology |
|---|---|
| Backend | Python / FastAPI |
| Frontend | React (under consideration) |
| Database | PostgreSQL |
| External API | Google Books API |
| Testing | pytest and frontend testing tools |
| Code Quality | SonarQube |
| Collaboration | GitHub Issues, Pull Requests, GitHub Actions |

The final platform and architecture will be decided by the team.

## Team Workflow

- The `main` branch represents the stable version of the project.
- Each task will be tracked through a GitHub Issue.
- Features will be developed in separate branches.
- Changes will be submitted through Pull Requests.
- Pull Requests should be reviewed before merging.
- Tests and code-quality checks will be introduced as development progresses.

## Development Status

The project is currently in its planning and initial setup phase.

Architecture decisions, installation instructions, test results, and screenshots will be added as the project evolves.
