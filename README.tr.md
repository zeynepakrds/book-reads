# BookReads 📚

BookReads, Goodreads'ten ilham alan ve oyunlaştırma özellikleri içeren bir kitap okuma takip uygulaması projesidir.

Bu proje, AI-Based Development dersi kapsamında yedi kişilik bir öğrenci ekibi tarafından geliştirilmektedir.

## Projenin Amacı

Amacımız, kitap takibini XP (deneyim puanı), okuma serileri (streak), kişisel hedefler ve kitap quizleriyle birleştirerek düzenli okuma alışkanlığı kazanmayı teşvik eden bir uygulama geliştirmektir.

## Planlanan Özellikler

- Google Books API ile kitap arama
- Kitapları okuma listelerine ayırma
- Okuma ilerlemesini takip etme
- Okuma etkinlikleriyle XP kazanma
- Günlük veya haftalık okuma serileri (streak) oluşturma
- Kitaplarla ilgili quizleri çözme
- Kişisel okuma istatistiklerini görüntüleme

Bu özellikler şu an **planlama aşamasındadır** ve proje boyunca aşamalı olarak geliştirilecektir.

## Önerilen Teknolojiler

| Katman | Teknoloji |
|---|---|
| Backend | Python / FastAPI |
| Frontend | React (değerlendirme aşamasında) |
| Veritabanı | PostgreSQL |
| Harici API | Google Books API |
| Test | pytest ve frontend test araçları |
| Kod Kalitesi | SonarQube |
| Takım Çalışması | GitHub Issues, Pull Requests, GitHub Actions |

Son platform ve mimari kararları ekip tarafından verilecektir.

## Takım Çalışma Düzeni

- `main` branch'i projenin kararlı sürümünü temsil eder.
- Her görev için bir GitHub Issue oluşturulması hedeflenir.
- Özellikler ayrı branch'lerde geliştirilecektir.
- Değişiklikler Pull Request (PR) üzerinden önerilecektir.
- PR'lar birleştirilmeden önce başka bir ekip üyesi tarafından incelenmelidir.
- Test ve kod kalitesi kontrolleri geliştirme sürecinde aşamalı olarak eklenecektir.

## Geliştirme Durumu

Proje şu anda planlama ve ilk kurulum aşamasındadır.

Mimari kararlar, kurulum yönergeleri, test sonuçları ve uygulama ekran görüntüleri proje geliştikçe eklenecektir.
